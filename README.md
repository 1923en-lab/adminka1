# ZHULDYZ STOM — система управления

Сайт на GitHub Pages + бесплатная база и вход через Firebase.
- Вы (владелец): отчёт, задачи, список людей. Вносить данные по врачам вы не можете.
- Администратор: вносит по каждому врачу количество пациентов и написанных планов, отмечает «сдал» по задачам.

Файлы: `index.html` (сайт), `config.js` (ваши настройки), `firestore.rules` (правила доступа), `napominanie-16-00.gs` (письмо-напоминание).

## Шаг 1. Firebase (бесплатный тариф Spark, карта не нужна)
1. Откройте console.firebase.google.com под своим аккаунтом Google → «Создать проект» (Google Analytics можно выключить).
2. Build → Authentication → «Начать» → способ входа «Электронная почта/пароль» → включить → сохранить.
3. Вкладка Users → «Добавить пользователя»: создайте два аккаунта (почта + пароль): ваш и администратора. Скопируйте у каждого значение **User UID**.
4. Build → Firestore Database → «Создать базу данных» → выберите регион → режим «производственный».
5. Вкладка «Правила»: вставьте содержимое `firestore.rules`, заменив `UID_ВЛАДЕЛЬЦА` и `UID_АДМИНИСТРАТОРА` на свои UID (в двух местах каждый) → «Опубликовать».
6. Настройки проекта (шестерёнка) → «Ваши приложения» → значок `</>` (веб) → зарегистрируйте приложение → скопируйте `firebaseConfig`.

## Шаг 2. config.js
Вставьте значения `firebaseConfig` и оба UID в `config.js`. Ключ apiKey не является секретом, защиту дают правила из шага 1.

## Шаг 3. GitHub
1. Создайте репозиторий и загрузите `index.html`, `config.js` (можно и остальные файлы).
2. Settings → Pages → Source: ветка main, папка root → Save. Адрес будет `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`.
3. Firebase → Authentication → Settings → Authorized domains → добавьте `ЛОГИН.github.io`.

## Шаг 4. Первый запуск
Откройте сайт, войдите под своей почтой. На вкладке «Люди» нажмите «Загрузить врачей…» (появится список из 7 врачей и «Администратор»). Войдите под админом и проверьте вкладку «Таблица дня».

## Шаг 5. Письмо в 16:00
Откройте script.google.com под аккаунтом zhuldyz.stom8@gmail.com → новый проект → вставьте `napominanie-16-00.gs` → впишите адрес сайта в `PAGE_URL` → в настройках проекта часовой пояс Asia/Almaty → запустите `testEmail`, затем один раз `setupTrigger`. Письма приходят каждый день примерно с 16:00 до 17:00, независимо от того, внесены ли данные.

## Если что-то не работает
Откройте сайт, нажмите F12 → Console и пришлите текст красных ошибок.
